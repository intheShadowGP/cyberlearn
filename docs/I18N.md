# Traduction FR / EN et banques de questions (Phase 5)

Ce document explique **comment ajouter ou traduire un contenu** sans casser la cohérence FR / EN.
Les tests (`npm test`, `npm run build`) font échouer toute divergence.

## Principes

- **Le français est la source.** L’anglais est une traduction humaine et professionnelle (pas de traduction automatique
  approximative), avec un vocabulaire de cybersécurité cohérent (voir le glossaire ci-dessous).
- **Mêmes identifiants dans les deux langues** (cours, sections, compétences, questions, options, exercices) : la
  progression, les révisions et les résultats survivent à un changement de langue.
- **Aucun mélange de langues** : il n’y a pas de repli silencieux sur l’autre langue en production. Le test de parité et le
  balayage e2e (fuite de français en anglais) l’interdisent. `PHASE5_COMPLETE` (`src/content/migration.ts`) rend la
  couverture globale obligatoire.
- La langue est une préférence (`prefs.lang`, `localStorage`), appliquée à `<html lang>`. Défaut : français.

## Interface

- Dictionnaires plats dans `src/i18n/fr/*.ts` (source) et `src/i18n/en/*.ts` (typés `Record<clés FR, string>` :
  une clé manquante en anglais fait échouer `npm run typecheck`).
- Variables : `{nom}`. Pluriels : deux clés `base_one` / `base_other`, appelées via `tp('base', n)`.
  Texte riche : `**gras**`, `` `code` ``, `*italique*` rendus par `<Inline text={t('clé')} />`.
- Dans un composant : `const { t, tp, lang, date, num } = useI18n();`. Hors composant : `t('clé')` (langue courante).
- Un composant qui affiche du contenu localisé doit appeler `useI18n()` pour se re-rendre au changement de langue.
- Les contenus structurés se lisent par `getCourses(lang)`, `getCourse(id, lang)`, `getModules(lang)`, `getLabs(lang)`,
  `getScenarios(lang)`, `getPaths(lang)`, `getExams(lang)`, `getVerification(id, lang)` et les chargeurs
  `loadCourseBody(id, lang)`… (jamais directement `COURSES` pour afficher du texte).

## Contenu d’un cours (dossier `src/content/courses/<id>/`)

| Fichier | Rôle |
| --- | --- |
| `meta.ts` | Métadonnées FR (structure + texte). `questionCount` = taille de la banque ; `quizSize` ≥ 8 |
| `meta.en.ts` | `metaText` : titre, résumé, objectifs, connaissances préalables, libellé de chaque compétence |
| `body.ts` / `body.en.ts` | Leçon, exercices, ressources. Importent `questions` depuis `./questions` / `./questions.en` |
| `solutions.ts` / `solutions.en.ts` | Corrigés des exercices (mêmes ids d’exercices) |
| `bank.ts` / `bank.en.ts` | **Banque de questions (source d’écriture)**, 40 à 60 questions, mêmes ids dans les deux langues |
| `questions[.en].ts`, `corrections[.en].ts` | **Générés** par `npm run banks` — ne jamais modifier à la main |

Structure de `body.en.ts` : mêmes `id` de sections, mêmes types de blocs dans le même ordre, mêmes nombres d’éléments dans
les listes et tableaux, mêmes `useCases`, `commonMistakes`, `bestPractices`, `keyPoints`, `practice` (ids, genres, nombre
d’étapes) et ressources (mêmes URL). Le test `parité FR / EN` vérifie tout cela.

## Écrire une banque de questions (`bank.ts`)

```ts
import type { BankItem } from '../../bank';
export const bank: BankItem[] = [
  { id: 'xx-q1', t: 'single', d: 1, s: ['skill-id'], p: 'Énoncé ?',
    o: ['Bonne réponse', 'Distracteur 1', 'Distracteur 2', 'Distracteur 3'],   // o[0] = bonne réponse
    e: 'Explication pédagogique (≥ 60 caractères).', w: { 1: 'Pourquoi le distracteur 1 est faux.' } },
  { id: 'xx-q2', t: 'multi', d: 2, s: [...], p: '…', k: 3, o: ['B1', 'B2', 'B3', 'D1', 'D2'], e: '…' }, // o[0..k-1] = bonnes
  { id: 'xx-q3', t: 'truefalse', d: 1, s: [...], p: '…', v: true, e: '…' },
  { id: 'xx-q4', t: 'short', d: 1, s: [...], p: '…', a: ['réponse acceptée', 'variante'], e: '…' },
  { id: 'xx-q5', t: 'open', d: 3, s: [...], p: '…', m: 'Réponse modèle', c: ['critère 1', 'critère 2'], e: '…' },
];
```

Règles (vérifiées par `src/content/bank-quality.test.ts`) :

- 40 à 60 questions par cours, ≥ 4 types, les trois difficultés représentées, aucun doublon d’énoncé dans la discipline.
- QCM unique : 4 ou 5 options ; QCM multiple : 4 à 6 options, 2 bonnes réponses ou plus.
- **Pas d’indice** : la bonne réponse n’est pas systématiquement la plus longue (≤ 40 % des QCM, longueur moyenne ≤ 115 %
  de celle des distracteurs), les distracteurs sont plausibles mais faux, jamais « toutes les réponses ci-dessus ».
- **Position équilibrée** : l’ordre d’écriture n’est pas l’ordre d’affichage. Le générateur répartit la position de la
  bonne réponse de façon reproductible (identique en FR et en EN) ; aucune position ne porte plus de 40 % des réponses.
- Vrai/faux : entre 30 % et 70 % de « vrai ».
- Chaque compétence du cours est évaluée par ≥ 3 questions ; chaque notion enseignée doit apparaître dans la banque.
- `bank.en.ts` reflète `bank.ts` : mêmes ids, types, difficultés, compétences, nombres d’options (`o`), `k`, `v`, clés de `w`
  et nombre de critères (`c`). Les réponses courtes acceptées (`a`) sont propres à chaque langue.

Après modification : `npm run banks` (régénère), puis `npm test`.

## Glossaire de traduction (vocabulaire de référence)

| Français | Anglais |
| --- | --- |
| cours / leçon / évaluation | course / lesson / assessment |
| valider (un cours) | pass (a course) |
| laboratoire | lab |
| parcours | learning path |
| compétence | skill |
| discipline | discipline (module) |
| mode libre | free mode |
| positionnement | placement |
| examen blanc | mock exam |
| répétition espacée | spaced repetition |
| pare-feu / journal / empreinte | firewall / log / hash (digest) |
| hachage / chiffrement | hashing / encryption |
| moindre privilège | least privilege |
| défense en profondeur | defense in depth |
| faux positif / faux négatif | false positive / false negative |
| élévation de privilèges | privilege escalation |
| chaîne de conservation | chain of custody |
| rançongiciel | ransomware |
| test d’intrusion | penetration test (pentest) |
| fournisseur d’identité | identity provider (IdP) |

Orthographe : anglais américain (« authorization », « behavior »). Les noms propres, sigles et commandes ne sont pas traduits.
